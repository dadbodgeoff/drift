# Studio sync: what Drift ships and what the Studio shows

The rule: **every user-visible addition to Drift ships with Studio support, or with a
linked paired Studio PR.** This file is the ledger. It lists each Drift feature, the
CLI or JSON surface it adds, the Studio surface that shows it, the status and the gap.
`CONTRIBUTING.md` ("Studio") says how a change keeps it current.
`tests/unit/coverage.test.ts` fails CI when Drift gains a subcommand, rule kind, skip
reason or hook message that the Studio does not handle or allowlist.

Statuses: **done** (shown, tested); **done here** (shown since the catch-up PR);
**not needed** (no user-visible JSON change); **allowlisted** (deliberately not shown,
with a reason in `src/shared/contract/coverage.ts`); **paired** (built with the
feature's own PR); **gap** (missing; the note says why).

The Studio was last updated in #16 (3215b84). The catch-up below covers #12 to #25.
