# Archived — Drift v2, full experiment

This branch is a historical snapshot, not an active line of development. **Do not open PRs against it.**

This is the fullest extent of the v2 cloud/Supabase direction: a demo app (`demo/`), infrastructure
manifests (`infrastructure/`), a wiki (`wiki/`), and Turbo/Vitest tooling layered on top of the
Postgres-backed core in [`archive/v2`](https://github.com/dadbodgeoff/drift/tree/archive/v2). The
scope kept growing; v3 (current [`main`](https://github.com/dadbodgeoff/drift/tree/main)) is the
walk-back — local-first, SQLite, no server, no demo app.

See [`docs/HISTORY.md`](https://github.com/dadbodgeoff/drift/blob/main/docs/HISTORY.md) on `main`
for the full story.
